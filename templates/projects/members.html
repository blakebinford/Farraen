Role guide
  • Project Manager: Full project oversight with edit access to drive content and welds.
  • Superintendent: Manages field execution with drive and weld edit access.
  • Quality Manager: Oversees quality processes with drive and weld edit access.
  • Quality Tech: Supports quality documentation with drive edit access but no weld edits.
  • Project Member: Standard contributor with drive and weld edit access.
  • Project Viewer: Read-only access to project information.
  • Client (Guest): Read-only access for external stakeholders.

Project viewing requires being both an organization member and a project member.
