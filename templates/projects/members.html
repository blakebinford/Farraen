Role descriptions
  • Project Manager: Full project oversight with Drive edit access. Does not edit welds.
  • Superintendent: Field execution with Drive edit access. Does not edit welds.
  • Quality Manager: Quality leadership with Drive and Weld edit access.
  • Quality Tech: Documentation support with Drive and Weld edit access.
  • Project Member: Standard contributor with Drive edit access. Does not edit welds.
  • Project Viewer: Read-only access to project information and Drive.
  • Client (Guest): Read-only access limited to the Weld Log and Repair Log.

Project viewing requires being both an organization member and a project member.
